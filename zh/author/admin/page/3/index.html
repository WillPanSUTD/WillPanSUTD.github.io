Fast Shape Retrieval Based on Differential Chain Code Descriptor and Fuzzy Contour Matching

一种轮廓匹配方法：将轮廓编码为差分链码序列，以滑动窗口式的模糊策略分段匹配短码段，并通过 SVD 对齐验证候选位置；在全部 8 幅测试图像上的平均距离均低于 Halcon 和 Smart。

1月 1, 2025

DeSC: Learning Deep Semantic Descriptor for NeRF Registration

DeSC 从 NeRF 与视角无关的嵌入空间中学习深度语义描述子，结合局部隐式光度信息、图卷积聚合、Transformer 上下文和密度感知光度一致性，实现鲁棒的 NeRF 与 NeRF 之间的配准。

1月 1, 2025

Calibration Method of Fringe Projection Based on High-Order Polynomial

一种用于相移轮廓术的快速标定方法：以高阶多项式描述像素坐标、绝对相位与三维坐标之间的映射，并用稀疏贪婪随机 Kaczmarz（SGRK）算法代替最小二乘法拟合多项式系数。

1月 1, 2025

A Reversible Grayscale Method Based on Bit-Field Multi-Channel Fusion Encoding

一种无需学习的可逆灰度化方法：把 RGB 图像转换到 HSV 空间，将量化后的色调、饱和度和明度写入一个 16 位灰度图像的各个位域，只需简单的位运算即可解码回 RGB。

1月 1, 2025

VeinTr: Robust end-to-end full-hand vein identification with transformer

VeinTr 以端到端方式从全手近红外静脉图像中识别身份，无需提取 ROI：卷积块和残差块提取局部特征，轻量 Transformer 进行全局聚合，MLP 解码器输出用于待测样本–数据库匹配的静脉特征。

10月 1, 2024

SemReg: Semantics-Constrained Point Cloud Registration

SemReg 是一种二维–三维跨模态点云配准方法：将 RGB 图像中的语义特征投影到点云上，引导交叉注意力和点匹配集中于语义相近的区域，在 3DMatch 和 3DLoMatch 上取得了最高的配准召回率。

9月 1, 2024

Segmentation-Driven Feature-Preserving Mesh Denoising

一种分割驱动的网格去噪方法：先用基于边的区域生长把含噪三角网格划分为若干区域，再逐区域独立去噪，使尖锐特征另一侧的面片不再干扰去噪结果。该分割主干可嵌入 BNF、UNF、GNF、L1 等现有去噪方法。

9月 1, 2024

TopFormer: Topology-Aware Transformer for Point Cloud Registration

TopFormer 是一种面向点云配准的拓扑感知 Transformer。它以“稀疏–稠密”方式编码点对结构：在稠密点上测得两个稀疏点之间的测地距离和基于法向的方向信息，使空间上相近、但沿表面相距很远的点更容易区分。

4月 1, 2024

Reconstruction of transparent objects using phase shifting profilometry based on diffusion models

以在透明物体上采集到的混叠条纹图为条件，扩散模型只生成由前表面反射的条纹图，从而可以用常规相移轮廓术重建透明物体。

4月 1, 2024

Generative deep-learning-embedded asynchronous structured light for three-dimensional imaging

APSNet 是一个在条件生成对抗网络框架下训练的类 U-Net 生成式网络，可分离投影仪与相机非同步工作时采集到的混叠条纹图，使标准相移法三维重建结果与同步采集的偏差不超过 8 μm。
