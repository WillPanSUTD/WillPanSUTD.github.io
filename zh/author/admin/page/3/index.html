Precision 3D volume measurement of transparent adhesives via spectrally optimized line laser scanning and enhanced centroid extraction

一种测量透明点胶体积的线激光扫描系统：黄绿色背景基板吸收穿过胶体的紫色激光，基于候选点机制和动态加权多因子评分（DWMF-SS）的光条中心提取具有较强的抗噪能力，体积测量的平均相对误差为 1.62%。

Photometric stereo-based defect detection for lithium battery top covers

锂电池顶盖的表面缺陷检测对保证电池的性能、可靠性和使用寿命至关重要。

1月 1, 2025

Parallel Grayscale Connected Component Analysis via Neighborhood Labeling and Global Region Mapping

一种在 GPU 上直接处理灰度图和深度图、无需二值化的连通域分析方法：局部邻域标记、边界检测，再在紧凑的区域 ID 空间中合并区域。处理一张 200 万像素的深度图约需 1.6 ms。

1月 1, 2025

Identifying frequency-domain operating deflection shapes and internal damage in structures using geometric vision method

本文提出一种几何视觉方法，用于频域工作变形振型（ODS）测量与结构内部损伤识别，包括基于 RANSAC 的双目标定、立体—时序匹配、ODS 估计和基于小波的损伤定位。

1月 1, 2025

GCMA6D: Graph Convolution and Cross-Modality Attention Fusion for 6D Pose Estimation

GCMA6D 是一种基于 RGB-D 的 6D 位姿估计网络：在点云分支中引入三维图卷积，在图像分支中引入大核注意力，并以跨模态注意力加 Squeeze-and-Excitation 通道重加权融合两路特征，面向遮挡和弱纹理物体。

1月 1, 2025

FPD: Fringe Photometric Deflectometry when Fringe Meets Photometric Stereo

FPD 将相位测量偏折术（PMD）与光度立体（PS）融合，按镜面反射分量和漫反射分量逐像素计算权重：高光区域以 PMD 为主，漫反射区域以 PS 为主，用于表面重建和缺陷检测。

1月 1, 2025

Fast Shape Retrieval Based on Differential Chain Code Descriptor and Fuzzy Contour Matching

一种轮廓匹配方法：将轮廓编码为差分链码序列，以滑动窗口式的模糊策略分段匹配短码段，并通过 SVD 对齐验证候选位置；在全部 8 幅测试图像上的平均距离均低于 Halcon 和 Smart。

1月 1, 2025

DeSC: Learning Deep Semantic Descriptor for NeRF Registration

DeSC 从 NeRF 与视角无关的嵌入空间中学习深度语义描述子，结合局部隐式光度信息、图卷积聚合、Transformer 上下文和密度感知光度一致性，实现鲁棒的 NeRF 与 NeRF 之间的配准。

1月 1, 2025

Calibration Method of Fringe Projection Based on High-Order Polynomial

一种用于相移轮廓术的快速标定方法：以高阶多项式描述像素坐标、绝对相位与三维坐标之间的映射，并用稀疏贪婪随机 Kaczmarz（SGRK）算法代替最小二乘法拟合多项式系数。

1月 1, 2025

A Reversible Grayscale Method Based on Bit-Field Multi-Channel Fusion Encoding

一种无需学习的可逆灰度化方法：把 RGB 图像转换到 HSV 空间，将量化后的色调、饱和度和明度写入一个 16 位灰度图像的各个位域，只需简单的位运算即可解码回 RGB。
