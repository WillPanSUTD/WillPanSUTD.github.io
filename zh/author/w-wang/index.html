W Wang

Weighted Point Cloud Normal Estimation

一种点云加权法向回归方法：权重回归器预测每个邻域点与中心点的相关程度，对比预训练则将每个局部块与其中心点的真实法向配对学习，从而在含噪的合成点云和真实点云上得到鲁棒且保持特征的法向。

7月 1, 2023

Random screening-based feature aggregation for point cloud denoising

一种基于学习的点云去噪方法：对每个局部块的特征进行随机筛选，并将较稠密局部块的全局特征融合到其较稀疏的子块中，从而提高对严重噪声和不规则点分布的鲁棒性。

1月 1, 2023
