Guoping Qiu

HLO: Half-kernel Laplacian Operator for surface smoothing

HLO 用半核拉普拉斯算子取代网格光顺中的均匀拉普拉斯算子：在每个顶点邻域的各个半窗口上计算拉普拉斯，并选取能量最小者，从而在只有一个参数的情况下保持特征、抑制收缩。

1月 1, 2020

Parallel Curvature Filter for High Performance Image Processing

并行曲率滤波（PCF）将曲率滤波中的 8 个投影距离计算转化为 GPU 上的卷积运算，单块 GPU 每秒可处理 332 亿像素，远快于在 CPU 上运行的原始曲率滤波。

1月 1, 2019
