Paper-Conference

SemReg: Semantics-Constrained Point Cloud Registration

SemReg 是一种二维–三维跨模态点云配准方法：将 RGB 图像中的语义特征投影到点云上，引导交叉注意力和点匹配集中于语义相近的区域，在 3DMatch 和 3DLoMatch 上取得了最高的配准召回率。

9月 1, 2024

TopFormer: Topology-Aware Transformer for Point Cloud Registration

TopFormer 是一种面向点云配准的拓扑感知 Transformer。它以“稀疏–稠密”方式编码点对结构：在稠密点上测得两个稀疏点之间的测地距离和基于法向的方向信息，使空间上相近、但沿表面相距很远的点更容易区分。

4月 1, 2024

WTAYOLO: A Detection Model for Weak Scratches on Metal Surfaces

WTAYOLO 用于检测锂电池等金属表面上的微弱划痕：光度立体成像降低表面反射带来的干扰，WTAConv 模块扩大感受野并引入通道与空间注意力。在不增加参数量的情况下，其 mAP50 达到 86.8%，比 YOLOv11n 提高 5.1%。

1月 1, 2024

Weighted Point Cloud Normal Estimation

一种点云加权法向回归方法：权重回归器预测每个邻域点与中心点的相关程度，对比预训练则将每个局部块与其中心点的真实法向配对学习，从而在含噪的合成点云和真实点云上得到鲁棒且保持特征的法向。

7月 1, 2023

3D reconstruction of moving object by double sampling based on phase shifting profilometry

借助触发控制装置，相机在每幅投射条纹期间拍摄两幅图像；再利用跟踪得到的物体运动，通过最小二乘相位模型从连续三幅图像中恢复相位，从而提高相移轮廓术重建运动物体的帧率。

1月 1, 2023

Parallel Curvature Filter for High Performance Image Processing

并行曲率滤波（PCF）将曲率滤波中的 8 个投影距离计算转化为 GPU 上的卷积运算，单块 GPU 每秒可处理 332 亿像素，远快于在 CPU 上运行的原始曲率滤波。

1月 1, 2019
