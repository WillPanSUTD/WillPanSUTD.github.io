SuP: Sub-cloud Driven Point Cloud Registration

SuP 把低重叠点云配准转化为高重叠子点云锚点对的挖掘问题，借助 DSAM、OPS、MPN 和合并匹配模块，从存在歧义的局部扫描中恢复可靠的对应关系。

Dynamic correlation network and structure-aware matching for robust point cloud registration

点云之间的相对旋转给可靠的对应关系估计带来了很大挑战。

An Improved Graph Attention Network for Semantic Segmentation of Industrial Point Clouds in Automotive Battery Sealing Nail Defect Detection

密封钉缺陷的准确检测对汽车电池的安全性和可靠性至关重要。

SemReg: Semantics-Constrained Point Cloud Registration

SemReg 是一种二维–三维跨模态点云配准方法：将 RGB 图像中的语义特征投影到点云上，引导交叉注意力和点匹配集中于语义相近的区域，在 3DMatch 和 3DLoMatch 上取得了最高的配准召回率。

9月 1, 2024

TopFormer: Topology-Aware Transformer for Point Cloud Registration

TopFormer 是一种面向点云配准的拓扑感知 Transformer。它以“稀疏–稠密”方式编码点对结构：在稠密点上测得两个稀疏点之间的测地距离和基于法向的方向信息，使空间上相近、但沿表面相距很远的点更容易区分。

4月 1, 2024

Gap measurement method based on projection lines and convex analysis of 3D point clouds

一种继电器间隙测量方法：将基于背光图像的快速二维投影线模型，与利用凸包和继电器质心确定支撑面的三维点云模型相结合。

1月 1, 2024

A Point Cloud Contour Extraction Method based on Plane Segmentation

一种物体点云轮廓提取方法：用 PCA 优化的 RANSAC 分割平面，将每个平面投影为二维图像，再根据图像梯度提取其边界。

1月 1, 2024

Weighted Point Cloud Normal Estimation

一种点云加权法向回归方法：权重回归器预测每个邻域点与中心点的相关程度，对比预训练则将每个局部块与其中心点的真实法向配对学习，从而在含噪的合成点云和真实点云上得到鲁棒且保持特征的法向。

7月 1, 2023

Towards uniform point distribution in feature-preserving point cloud filtering

一种点云滤波方法：在边缘感知的数据项之外加入排斥项，在去除噪声、保留尖锐特征的同时，使滤波后的点分布较为均匀。

1月 1, 2023

Random screening-based feature aggregation for point cloud denoising

一种基于学习的点云去噪方法：对每个局部块的特征进行随机筛选，并将较稠密局部块的全局特征融合到其较稀疏的子块中，从而提高对严重噪声和不规则点分布的鲁棒性。
