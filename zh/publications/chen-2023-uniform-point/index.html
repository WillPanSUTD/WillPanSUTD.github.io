Towards uniform point distribution in feature-preserving point cloud filtering

面向均匀点分布的特征保持点云滤波
S Chen, J Wang, Wei Pan, S Gao, M Wang, X Lu
Computational Visual Media, 9(2):249–263
↓ PDF { } BibTeX DOI

一句话看懂一种点云滤波方法：将边缘感知的数据项与排斥项结合，在去噪并保留尖锐棱边的同时，让滤波后的点均匀分布，而不是在棱边附近留下空洞。

问题背景

扫描得到的原始点云含有噪声，因此在上采样、曲面重建等后续处理之前通常需要先滤波。理想的滤波方法应当把含噪点移回真实曲面，保留尖锐的棱边和角点，并使点分布均匀。现有方法往往只能兼顾其中一部分。基于位置的方法（如 CLOP）平滑效果好，但由于不利用法向信息，容易抹平尖锐特征。基于法向的方法能更好地保留尖锐棱边，但滤波后的点往往分布不均；其中一些方法虽然加入了排斥项，仍会在棱边附近留下空洞。深度学习方法需要带真值的含噪点云作为训练数据，且基于局部块处理，即使加入排斥损失，结果仍分布不均，对稀疏或采样不均匀的输入也难以处理。

本文建立在此前一种低秩滤波方法的边缘感知点更新之上。单独使用这种更新时，点会向尖锐棱边移动并在那里聚集，在棱边旁留下空洞。这些空洞会影响上采样和曲面重建等后续处理。

方法原理

该方法分为两个阶段：先平滑点的法向，再利用这些法向更新点的位置。位置更新最小化两项之和：一是边缘感知的数据项，在逼近含噪曲面的同时保留几何特征；二是排斥项，用于控制点的分布。

  1. 含噪输入。 输入是带法向的含噪点云；若只有点坐标，则用主成分分析（PCA）估计初始法向。
  2. 法向滤波。 用双边滤波平滑法向。滤波后点的质量在很大程度上取决于这些法向的质量。
  3. 数据项。 对每个点及其局部块中的每个邻域点，更新会调整两点连线与两点法向之间的夹角，使该连线垂直于两点的法向。这使点回到真实曲面并保留尖锐特征，但单独使用时会把点推向棱边，留下空洞。
  4. 排斥项。 基于点坐标和法向的排斥项让邻域点沿垂直于邻点法向的方向相互推开，其权重随距离平滑衰减；参数 µ 控制排斥力的大小。
  5. 迭代。 两项合并为对每个点的一次梯度下降更新（论文式 (6)），在 k 个最近邻点构成的局部块上计算，共迭代 t 次。大部分实验取 k = 30、µ = 0.3、t = 5（表 1）。

对比方法包括基于位置的 CLOP、基于法向的 GPF 和 RIMLS，以及三种深度学习方法 TotalDenoising、PointCleanNet 和 Pointfilter（简称 TD、PCN 和 PF）。定量测试使用五个添加了 0.5% 或 1.0% 高斯噪声的模型（Bunnyhi、Rockerarm、Icosahedron、Dodecahedron 和 Kitten）。该方法在五个模型中的四个上倒角距离最低，在三个上均方误差最低。原始扫描点云（Nefertiti、BuddhaStele、Realscan 和 David）没有真值，只做视觉对比；论文指出，该方法在尖锐棱边、BuddhaStele 的台阶和人脸特征等细节上保持得比其他方法更好。作者将误差较低归因于点分布更均匀：例如 RIMLS 在部分情况下视觉效果相当，但由于点分布不均，其误差在多数情况下更大。去掉排斥项后，部分点会聚集在棱边上。

论文还测试了不同点密度、0.5% 至 3.0% 的噪声水平、不规则采样、带孔模型以及室内场景。作者指出两点局限：作为基于法向的方法，它依赖输入法向的质量；在噪声很高时效果可能变差（1.5% 的噪声已比 0.5% 和 1.0% 更具挑战性）。此外，严重破坏曲面的大孔洞难以填补，最佳邻域大小 k 也强烈依赖于点云密度。
