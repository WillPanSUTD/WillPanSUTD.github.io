TTA-MAC: Test-Time Adaptive Metric Calibration with a Signed-SDF Trust Region for Monocular 6D Object Pose Alignment

TTA-MAC：基于带符号 SDF 信赖域的测试时自适应度量标定，用于单目 6D 物体位姿对齐
Istiak Ahamed, Wei Pan, MD Mehedy Hasan, Lei Lu
Journal article
{ } BibTeX
— 摘要

问题背景

借助基础检测模型和单目深度模型，单张 RGB 图像的零样本 6D 物体位姿估计进展迅速。据作者分析，仍有一个核心瓶颈：度量尺度的确定。单目深度能提供丰富的相对几何信息，但其尺度和偏移在每个物体实例上都存在偏差。CAD-MAC 等基于 CAD 的全局仿射标定能减小这一偏差，但剩余残差仍可能明显偏离高斯分布：在 LineMod-Occlusion 上使用 DAv2 深度模型时，残差偏度为 +4.5，超额峰度为 +36。因此，逐实例优化若采用高斯先验，与实际误差分布并不匹配。

方法原理

TTA-MAC 是一个以 CAD 为锚点、在测试时运行的优化层。它的输入是冻结的检测器、冻结的单目深度主干网络、初始位姿和物体的 CAD 模型，只优化八个几何变量：单目深度的两个标定参数和 6D 位姿。

  • 逐实例 MAP 问题。 把由深度得到的点云与 CAD 模型生成的带符号距离场对齐。
  • 重尾先验。 用 Student-t 先验描述重尾分布的标定残差。
  • 信赖域。 优化在带三重门控的信赖域内进行，并可回退到迄今最优的状态。关键的保护措施是一道基于带符号 SDF 的门控，统计伪深度点云落在 CAD 体积内部的比例，用于发现点云穿入物体、落入错误收敛区域的状态；这种失效在普通 ICP 或无符号距离对齐中无法察觉。

实验结果

与 CAD-MAC+ICP 基线相比，在 LineMod-Occlusion 上中位 ADD 误差从 44.0 mm 降至 31.3 mm，成功率（ADD 小于物体直径的 10%）从 10.4% 升至 14.3%。在 LineMOD 的 18,273 个实例上，中位 ADD 从 43.5 mm 降至 30.5 mm，成功率从 17.3% 升至 23.3%。在其他数据集上的迁移效果有限：YCB-V 上中位 ADD 从 41.1 mm 降至 38.3 mm，TUD-L 上从 59.5 mm 降至 55.6 mm，这些实验也暴露出仍存在的阈值和过度优化问题。作者将可见性感知、对称性感知和对遮挡稳健的信赖域列为后续方向。
