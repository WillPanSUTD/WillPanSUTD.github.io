WTAYOLO: A Detection Model for Weak Scratches on Metal Surfaces

WTAYOLO：金属表面微弱划痕检测模型
Weijin Xie, Wei Pan, Simi Li, Qi Zeng, Huayong Li
Proceedings of the 2024 7th International Conference on Sensors, Signal and Image Processing, 22-28
{ } BibTeX DOI

一句话看懂WTAYOLO 用于发现反光锂电池表面上的微弱划痕：光度立体成像降低表面反射带来的干扰，WTAConv 模块强化划痕特征，在不增加参数量的情况下 mAP50 达到 86.8%。

问题背景

锂电池表面的划痕会显著影响其电化学性能和运行安全，因此严格的划痕检测对保证产品质量至关重要。然而，锂电池材料具有反光特性，划痕本身又有特殊的形态特征，这使划痕检测算法仍面临重大挑战。

方法原理

WTAYOLO 是一个面向金属表面微弱划痕的检测模型。它结合光度立体成像来应对表面反光，并引入新模块 WTAConv，增强从图像中提取划痕特征的能力。

  1. 光度立体成像。 WTAYOLO 采用光度立体系统，降低表面反射带来的干扰。
  2. 扩大感受野。 WTAConv 模块扩大感受野，增强从图像中提取划痕特征的能力。
  3. 通道与空间注意力。 WTAConv 通过通道注意力和空间注意力机制强化重要特征，同时抑制冗余信息。
  4. 划痕检测。 模型检测出细微划痕。

实验结果

mAP50 达到 86.8%，比基线模型 YOLOv11n 提高 5.1%，且未增加参数量。

作者总结认为，该方法在精度与模型成本效益之间取得了有效平衡，为工业应用提供了有效的解决方案。
