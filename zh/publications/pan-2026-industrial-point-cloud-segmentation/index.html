An Improved Graph Attention Network for Semantic Segmentation of Industrial Point Clouds in Automotive Battery Sealing Nail Defect Detection

一种改进的图注意力网络：面向汽车电池密封钉缺陷检测的工业点云语义分割
Wei Pan, Yuhao Wu, Wenming Tang, Yunzhi Zhang, Qinghua Lu
Engineering Applications of Artificial Intelligence, 163(1):112793
↓ PDF { } BibTeX DOI ↗ Code

一句话看懂LGASS 直接在三维激光扫描点云中分割电池密封钉的焊接缺陷，其图注意力聚焦于相邻点法向量发生变化的位置，在真实产线数据上 mIoU 达到 79.26%。

问题背景

密封钉用于封堵汽车动力电池的注液孔，通过激光焊接固定。焊接过程可能产生爆点、熔珠、针孔等缺陷，影响电池的安全性和耐久性。金属表面反光强、缺乏纹理，二维成像难以可靠检测：需要频繁重新调整打光，误检率也较高。因此，传统检测方案先用二维视觉定位缺陷，再用三维视觉进行测量。这种多阶段流程复杂、效率较低，误差还会在各阶段之间累积。

三维点云可以直接反映表面形貌，但许多先进的分割网络（如 Point Transformer 和 Swin3D）在很大程度上依赖 RGB-D 或强度信息；当只有几何数据可用时，其鲁棒性受到限制，而这正是反光工业零件上的常见情况。缺陷本身也难以学习：同一类缺陷的形状可能差异很大；一帧约 10 万个点的扫描中，缺陷点只有约 1000 个；而在缺陷边界附近，点的坐标与周围表面几乎没有差别。

方法原理

LGASS（Local Graph Attention for Semantic Segmentation，局部图注意力语义分割）直接在三维点云上分割缺陷，在单一阶段内同时完成缺陷定位与几何量化。它只使用几何信息：网络输入是每个点的表面法向量，点的坐标则用于确定哪些点互为近邻。网络采用类 U-Net 的编码器–解码器结构，核心是两个新模块，一个用于注意力计算，一个用于池化。

  1. 扫描焊缝。 三维激光轮廓仪（OPT-LPC20，405 nm 蓝色激光线）扫描密封钉，横向分辨率约 0.05 mm。改进的 RANSAC 算法拟合密封钉与电池顶盖的参考平面，再以密封钉中心为圆心划定圆形区域，提取待检测的焊缝区域。
  2. 关注法向量。 几乎所有缺陷区域都表现出明显的高度和法向量变化。在缺陷边界附近，相邻两点的坐标几乎相同，法向量却明显不同，因此相邻点之间的法向量差异是识别缺陷的关键指标。
  3. 局部图注意力滤波器（LGAF）。 每个点与其 k 个最近邻相连。对每个近邻，LGAF 计算点自身特征与其到该近邻的特征差之间的相关性，并按两点的空间距离加权，得到注意力权重；再按这些权重聚合近邻特征。法向量差异越大，注意力权重越高，网络因而聚焦于缺陷边界。
  4. 空间注意力图池化（SAG-Pooling）。 编码器下采样时，每个点的得分是学习得到的空间注意力权重与其相对近邻的法向量差异之积。只保留排名靠前的点，因此只有在空间上重要、几何上又有区分度的点（例如缺陷边缘上的点）才会被保留。
  5. 逐点分类。 解码器由带位置编码的图卷积模块构成，逐层上采样回到完整点集，并通过跳跃连接融合编码器特征。网络为每个点分配六个类别之一：正常表面，或五类缺陷之一（爆点、凹坑、翘曲、熔珠、针孔）。训练时采用类别加权损失，提高少数缺陷类别的影响。

实验结果

在密封钉数据集上，mIoU（各类别交并比的平均值）达到 79.26%，总体精度（OA）达到 99.43%（五次运行的平均值），高于 PTv3（mIoU 75.13%）和 OA-CNN（74.04%）（表 4）。
针孔类 IoU 为 65.23%，对比方法最高为 60.04%（表 4）。
与采用标准图卷积和池化的基线相比，LGAF 与 SAG-Pooling 共同带来 2.59 个百分点的 mIoU 提升（表 5）。
在 RTX 4070 GPU 上处理一个样本耗时 220.9 ms（表 6）。

作者为此构建了一个新数据集，采集自检测产线上的真实密封钉，缺陷均为自然产生：共 271 个正常样本和 658 个缺陷样本，涵盖五类缺陷（爆点 170、凹坑 112、翘曲 132、熔珠 102、针孔 142；表 1）。代码和数据集已在线公开。在这一仅用几何信息的设定下，LGASS 与 GACNet、PointNet、PointNet++、Point Transformer（PTv1 和 PTv3）以及 OA-CNN 进行了比较。在五个不同随机种子下，其 mIoU 保持在 78.97% 至 79.61% 之间，并在五类缺陷中的四类（凹坑、熔珠、翘曲、针孔）上取得了最高 IoU。

消融实验说明了性能提升的来源。用 LGAF 替换图卷积使 mIoU 提高 2.19 个百分点，单独使用 SAG-Pooling 提高 0.46 个百分点，两者结合提高 2.59 个百分点（表 5）。法向量是更好的输入：在输入消融实验中，仅用法向量时 mIoU 为 79.23%，仅用坐标时为 76.94%，两者同时输入时为 78.31%（表 7）。类别加权损失提高了少数类别的 IoU，针孔提高 2.3 个百分点，熔珠提高 2.13 个百分点，mIoU 由 78.73% 提升至 79.26%（表 8）。推理时约占用 2.8 GB 显存。作者也指出，LGASS 在高度内凹的几何形状上可能表现欠佳，例如带有重叠缺陷的凹型密封钉，此时固定的 k 近邻图限制了长距离上下文建模；针孔等稀有类别的 IoU 也仍低于其他类别。
