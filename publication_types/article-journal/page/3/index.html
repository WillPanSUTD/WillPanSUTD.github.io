Article-Journal

Generative deep-learning-embedded asynchronous structured light for three-dimensional imaging

APSNet, a generative U-Net-style network trained in a conditional GAN framework, separates the aliased fringe patterns captured when projector and camera run without synchronisation, so standard phase-shifting 3D reconstruction matches the synchronised result to within 8 μm.

Jan 1, 2024

Gap measurement method based on projection lines and convex analysis of 3D point clouds

A relay gap measurement method that pairs a fast 2D projection-line model, built on backlit images, with a 3D point-cloud model that finds the support surface from a convex hull and the relay's centroid.

Jan 1, 2024

A Point Cloud Contour Extraction Method based on Plane Segmentation

A contour extraction method for object point clouds that segments planes with PCA-optimised RANSAC, projects each plane into a 2D image and extracts its boundary from image gradients.

Jan 1, 2024

Kinematic target surface sensing based on improved deep optical flow tracking

An improved RAFT optical-flow network with normalised cross-correlation tracks a moving object directly in its fringe-pattern images, so phase-shifting profilometry can reconstruct objects undergoing any 2D movement with an ordinary monochrome camera.

Nov 1, 2023

Deep learning-enabled 3D multimodal fusion of cone-beam CT and intraoral mesh scans for clinically applicable tooth-bone reconstruction

DDMF automatically fuses cone-beam CT (CBCT) and intraoral scans into 3D tooth crown-root-bone models: deep networks segment both scans, and a curvature-based jaw split, two-stage registration and crown replacement merge them, reaching a 0.17 mm average surface distance to expert models.

Sep 1, 2023

Towards uniform point distribution in feature-preserving point cloud filtering

A point cloud filtering method that adds a repulsion term to an edge-aware data term, so that noise is removed and sharp features are kept while the filtered points stay relatively evenly distributed.

Jan 1, 2023

Random screening-based feature aggregation for point cloud denoising

A learning-based point cloud denoising method that randomly screens the features of each local patch and fuses the global feature of the denser patch into its sparser sub-patch, improving robustness to severe noise and irregular point distributions.

Jan 1, 2023

3D reconstruction of the moving object with double-shooting based on phase shifting profilometry

A phase-shifting profilometry method in which the camera captures each projected fringe pattern twice, extracts phase under the resulting mixed phase shift using tracked object motion, and reuses images to raise the reconstruction frame rate of moving objects.

Jan 1, 2023

Automated reconstruction of multiple objects with individual movement based on PSP

An automated phase-shifting profilometry method for several objects that move independently of each other: each object is identified, tracked with KCF and given its own rotation and translation from SIFT feature points, and its phase is then retrieved with that movement.

Sep 1, 2020

Iteratively weighted principal component analysis and orientation consistency for normal estimation in point cloud

Iteratively Weighted PCA (IWPCA) estimates point cloud normals by repeating the local plane fit with bilateral spatial and normal weights, then makes the normal orientations consistent with a centroid-based pre-flip followed by minimal-spanning-tree propagation.
