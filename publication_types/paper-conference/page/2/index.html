SemReg: Semantics-Constrained Point Cloud Registration

SemReg is a 2D–3D cross-modal registration method that projects semantic features from RGB images onto point clouds and uses them to focus cross-attention and matching on semantically similar regions, achieving the best registration recall on 3DMatch and 3DLoMatch.

Sep 1, 2024

TopFormer: Topology-Aware Transformer for Point Cloud Registration

TopFormer is a topology-aware Transformer for point cloud registration. A sparse-through-dense encoding gives each pair of sparse points the geodesic distance and normal-based direction measured on the dense points, so points that are close in space but far apart along the surface are easier to tell apart.

Apr 1, 2024

WTAYOLO: A Detection Model for Weak Scratches on Metal Surfaces

WTAYOLO detects weak scratches on metal surfaces such as lithium batteries by combining photometric stereo imaging, which reduces interference from surface reflections, with a WTAConv module that enlarges the receptive field and uses channel and spatial attention. Its mAP50 reaches 86.8%, 5.1% above YOLOv11n, without increasing the number of parameters.

Jan 1, 2024

Weighted Point Cloud Normal Estimation

A weighted normal regression method for point clouds: a weight regressor predicts how relevant each neighbouring point is to the central point, and contrastive pre-training pairs each patch with its ground-truth normal, giving robust, feature-preserving normals on noisy synthetic and real-world point clouds.

Jul 1, 2023

3D reconstruction of moving object by double sampling based on phase shifting profilometry

A trigger device makes the camera capture two images for every projected fringe pattern; a least-squares phase model that uses the tracked object motion then recovers the phase from three consecutive images, raising the frame rate of phase-shifting profilometry for moving objects.

Jan 1, 2023

Parallel Curvature Filter for High Performance Image Processing

A parallel curvature filter (PCF) that computes the curvature filter's eight projection distances as convolutions on the GPU, so that a single GPU processes 33.2 gigapixels per second, much faster than the original curvature filter on CPU.

Jan 1, 2019

Design of LEGO Assembly Transformation

A design method for reassembling an existing LEGO model into a new target shape, laying the algorithmic groundwork for the full transformation pipeline.

Jan 1, 2017

Moving Sequence Generation Based on Hungarian Method for Pick-and-Place Process

Optimal moving sequence generation for robotic pick-and-place assembly using the Hungarian assignment algorithm, minimizing travel cost in automated 3D construction.
