3D Surface Matching Based on Adaptive Threshold and Curvature Map

Jiajun Qiu, Ling Cao, Yunzhi Zhang, Lizhe Chen, Siyuan He, Wei Pan
2026 9th International Conference on Image and Graphics Processing (ICIGP), 419-424
{ } BibTeX DOI

In one sentenceFor single-view 3D scans of industrial workpieces: keep only the high-curvature points of the model via an adaptive threshold on its curvature map, then align it to the scene scan with descriptor-based coarse matching and ICP.

The problem

In industrial defect inspection and robotic sorting, 3D scanners have a limited acquisition range, so each scan yields a single point cloud or depth map taken from one viewpoint. This makes surface matching difficult: feature points are sparse, there is excessive redundant data, and the overlap rate is low.

How it works

The method matches a 3D workpiece model against a scene point cloud. It first reduces the model to its high-curvature feature domains, selected with an adaptive threshold, and then matches in two stages, coarse and fine.

  1. Depth and curvature maps. The model point cloud is converted into a depth map, and a surface curvature map is calculated from it.
  2. Adaptive threshold segmentation. An adaptive threshold iterative segmentation algorithm eliminates redundant points and retains the geometrically significant high-curvature feature points as the reduced model point cloud.
  3. Coarse matching. A coarse matching algorithm based on an integral volume descriptor identifies the approximate pose of the target point cloud within the scene point cloud, which the authors report improves coarse matching accuracy and robustness and reduces the dependence of ICP iterations on the initial pose.
  4. Fine matching. The iterative closest point (ICP) algorithm then achieves fine surface matching.

Results

Compared with conventional surface matching algorithms and manual threshold adjustment methods, the method achieves higher matching precision, aligning target workpieces accurately without misalignment or positional deviations.
In simulated low-to-medium noise environments it still matches correctly.
