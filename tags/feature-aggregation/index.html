Feature Aggregation

Random screening-based feature aggregation for point cloud denoising

A learning-based point cloud denoising method that randomly screens the features of each local patch and fuses the global feature of the denser patch into its sparser sub-patch, improving robustness to severe noise and irregular point distributions.

Jan 1, 2023
