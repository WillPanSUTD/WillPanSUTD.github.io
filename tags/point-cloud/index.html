SuP turns low-overlap point cloud registration into high-overlap sub-cloud anchor mining, using DSAM, OPS, MPN, and merge-to-match to recover reliable correspondences from ambiguous partial scans.

SemReg: Semantics-Constrained Point Cloud Registration

SemReg is a 2D–3D cross-modal registration method that projects semantic features from RGB images onto point clouds and uses them to focus cross-attention and matching on semantically similar regions, achieving the best registration recall on 3DMatch and 3DLoMatch.

Sep 1, 2024

TopFormer: Topology-Aware Transformer for Point Cloud Registration

TopFormer is a topology-aware Transformer for point cloud registration. A sparse-through-dense encoding gives each pair of sparse points the geodesic distance and normal-based direction measured on the dense points, so points that are close in space but far apart along the surface are easier to tell apart.

Apr 1, 2024

Gap measurement method based on projection lines and convex analysis of 3D point clouds

A relay gap measurement method that pairs a fast 2D projection-line model, built on backlit images, with a 3D point-cloud model that finds the support surface from a convex hull and the relay's centroid.

Jan 1, 2024

A Point Cloud Contour Extraction Method based on Plane Segmentation

A contour extraction method for object point clouds that segments planes with PCA-optimised RANSAC, projects each plane into a 2D image and extracts its boundary from image gradients.

Jan 1, 2024

Weighted Point Cloud Normal Estimation

A weighted normal regression method for point clouds: a weight regressor predicts how relevant each neighbouring point is to the central point, and contrastive pre-training pairs each patch with its ground-truth normal, giving robust, feature-preserving normals on noisy synthetic and real-world point clouds.

Jul 1, 2023

Towards uniform point distribution in feature-preserving point cloud filtering

A point cloud filtering method that adds a repulsion term to an edge-aware data term, so that noise is removed and sharp features are kept while the filtered points stay relatively evenly distributed.

Jan 1, 2023

Random screening-based feature aggregation for point cloud denoising

A learning-based point cloud denoising method that randomly screens the features of each local patch and fuses the global feature of the denser patch into its sparser sub-patch, improving robustness to severe noise and irregular point distributions.
