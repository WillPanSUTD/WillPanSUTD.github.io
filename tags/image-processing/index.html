Image Processing

A Grayscale-Compatible Color Encoding via 8-bit HSV Bit-Packing and Lightweight Refinement

A colour image is stored as a single 16-bit channel whose high byte is exactly the standard BT.601 grayscale image and whose low byte carries a 4+4-bit hue/saturation hint; a deterministic HSV inverse plus a 0.47 M-parameter U-Net restores the colour.

Jan 1, 2026

Parallel Grayscale Connected Component Analysis via Neighborhood Labeling and Global Region Mapping

A parallel grayscale connected-component analysis method based on neighborhood labeling and global region mapping for faster region extraction.

Jan 1, 2025

A Reversible Grayscale Method Based on Bit-Field Multi-Channel Fusion Encoding

A non-learning reversible grayscale method that converts an RGB image to HSV and packs quantized hue, saturation and value bit fields into a single 16-bit grayscale image, which decodes back to RGB with simple bitwise operations.

Jan 1, 2025

Parallel Curvature Filter for High Performance Image Processing

A parallel curvature filter (PCF) that computes the curvature filter's eight projection distances as convolutions on the GPU, so that a single GPU processes 33.2 gigapixels per second, much faster than the original curvature filter on CPU.
